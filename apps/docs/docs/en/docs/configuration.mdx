# Configuration and models

A3S stores product configuration in ACL, the Agent Configuration Language.
`config.acl` is parsed by `a3s-acl`; it is not TOML or HCL.

## Configuration layers

Resolution order:

1. `--config PATH` or `A3S_CONFIG_FILE`
2. `.a3s/config.acl`, searched upward from the effective workspace
3. `~/.a3s/config.acl`

An explicit file wins. The workspace layer overrides the user layer. `-C`
changes the effective workspace before relative paths are resolved.

```bash
a3s config path
a3s config paths
a3s config init
a3s config init --scope workspace
a3s config show
a3s config validate
a3s config edit --scope workspace
```

`config show` prints a redacted effective view. `config validate` checks both
ACL syntax and Code configuration semantics.

## Select a model

```bash
a3s model list
a3s model current
a3s model use openai/my-model
a3s model use codex/gpt-5.2-codex
a3s model use openai/my-model --scope workspace
a3s model reset --scope user
```

Model IDs are source-qualified: `openai/...`, `claude-code/...`, `codex/...`,
`kimi/...`, `workbuddy/...`, or `a3s-os/...`. `model use` verifies that the
route is currently callable before updating `default_model` in the selected
ACL layer.

Claude Code, Codex, Kimi, and WorkBuddy retain ownership of their local login
state. The CLI reads availability without copying OAuth credentials into
`config.acl`.

## A3S OS account

After configuring an OS endpoint in ACL:

```bash
a3s auth login os
a3s auth status os
a3s auth logout os
```

An existing token can be read from protected standard input:

```bash
printf '%s' "$A3S_OS_TOKEN" | a3s auth login os --token-stdin
```

Local Code, Web, files, MCP, Memory, and Research do not require OS login.
Remote Runtime operations, hosted assets, and trusted ViewLinks do.

## Workspace data

Default state lives under the workspace `.a3s/` directory:

| Path | Content |
| --- | --- |
| `.a3s/config.acl` | Workspace configuration |
| `.a3s/tui/sessions/v1/sessions` | Code session snapshots |
| `.a3s/tui/session-state/v1` | TUI-owned session state |
| `.a3s/agents` | Agent definitions |
| `.a3s/mcps` | MCP assets |
| `.a3s/skills` | Skill assets |
| `.a3s/flows` | Flow assets |
| `.a3s/memory` | Workspace Memory |

ACL fields and dedicated environment variables can override these directories.
`a3s config paths` prints the paths used by the current invocation.
