# Web

`a3s web` 启动本地 Web host，默认入口是 `#home` 工作区。Web 使用与终端相同的
Code Core，提供任务会话、代码编辑、Git review、文件管理和 live preview。
Knowledge 是单独的内置入口。

## 启动

```bash
a3s web
a3s web -d
a3s web -d --replace
```

- 前台模式把日志留在当前终端。
- `-d` 启动或复用当前工作区的受管后台实例。
- `--replace` 只替换通过身份校验的 A3S 实例，不会终止占用端口的无关进程。

## 管理后台实例

```bash
a3s web status
a3s web open
a3s web logs
a3s web logs --follow
a3s web stop
```

实例身份与工作区绑定。重复启动会先检查已有服务的健康和所有权，再决定复用或报错。

## 地址与资源

```bash
a3s web --host 127.0.0.1 --port 4090
a3s web --web-dir ./apps/web/dist
a3s web --api-only
```

默认 host 是 `127.0.0.1`。`A3S_CODE_WEB_HOST` 与 `A3S_CODE_WEB_PORT` 可以设置默认值。
端口 `0` 会选择可用端口。

官方 release 与 Homebrew 包携带 Web 资源。Cargo 安装可在首次启动时下载匹配版本的资源；
`--offline` 或 `A3S_NO_AUTO_INSTALL=1` 禁止下载。

## 网络边界

Code API 可以读写工作区并启动工具，因此默认只监听 loopback。需要远程访问时，应在外层增加
认证、TLS 和明确的网络策略，不要把工作区 API 直接暴露到不受信任网络。

Live preview 只接受工作区静态文件和 localhost/loopback 服务。静态页面运行在
opaque-origin sandbox 中，不能把任意远程地址变成本地代理。
