# A3S CLI

`a3s` 是 A3S 的统一命令入口。Code、Web 和 Research 随 CLI 一起交付；
Box、Search、Use 等独立组件由 CLI 发现、安装和调用。

## 快速开始

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://raw.githubusercontent.com/A3S-Lab/a3s/main/install.sh | sh

cd /path/to/project
a3s config init
a3s model list
a3s code
```

安装器默认把 `a3s` 写入 `~/.local/bin`。如果命令不在 `PATH` 中，安装器会打印对应的
shell 配置。

## 主要入口

| 命令 | 作用 |
| --- | --- |
| `a3s code` | 打开终端智能体工作台。 |
| `a3s code exec "..."` | 在当前工作区执行一次非交互任务。 |
| `a3s web` | 启动本地 Web。 |
| `a3s code research "..."` | 运行带来源记录的 Research。 |
| `a3s config ...` | 初始化、检查和编辑 ACL 配置。 |
| `a3s model ...` | 查看并选择可调用模型。 |
| `a3s list` / `a3s doctor` | 检查组件、安装来源和运行条件。 |
| `a3s install` / `a3s upgrade` | 管理独立 A3S 组件。 |

## 交付边界

初次安装包含 CLI、Code 运行时和终端界面。官方 release 与 Homebrew 包还包含 Web
资源和受支持平台上的 WebView helper。独立产品不会因为执行 `a3s list` 或
`a3s --help` 而下载。

所有路径都服从同一组全局选项：

```bash
a3s -C /path/to/project --config ./team.acl --offline code
a3s --output json doctor
```

- `-C` 决定工作区。
- `--config` 固定一份 ACL 文件。
- `--offline` 禁止网络和首次使用下载。
- `--non-interactive` 禁止交互确认。
- `--output human|json|jsonl` 决定根命令的输出格式。
