A3S Gateway 当前稳定版是 1.0.12。它是一份 ACL 配置驱动的 Rust 数据面：接收流量，选择允许且健康的后端，并在不中断现有请求的前提下切换完整配置快照。

它不是 Cloud 控制面，也不负责创建模型副本、保存租户、调度工作负载或代替 Coding Agent。

## AI 请求与普通反向代理有什么不同

主要差别不在 URL，而在生命周期。

- SSE 和 WebSocket 可能持续几分钟，不能把整个响应缓存后再返回。
- 首包超时、流空闲超时和总时长是三个不同指标。
- 一旦上游已经开始返回，Gateway 不能静默切换到另一个模型重试。
- 模型授权不仅看路径，还要看 endpoint、model grant、快照版本和并发额度。
- 下游断开时，上游连接、后端计数和用量记录必须一起释放。

Gateway 现在为 SSE 提供独立的响应头、空闲流和总操作时限，并通过 drop guard 清理请求与连接计数。

## 一个请求只读取一份运行快照

```text
ACL 或 Cloud snapshot
        │
        ▼
校验 ──> 编译 ──> 原子切换 ──> active snapshot
                                  │
client ─> route ─> middleware ─> service ─> healthy backend
```

新配置先完整校验。失败的 reload 不会覆盖上一份可用配置。请求路径不需要同步访问 Cloud API、PostgreSQL 或调度器。

这是 Gateway 最重要的约束：控制面可以暂时不可用，已经授权且仍在有效期内的流量仍由本地快照处理。

## 当前协议与运维面

稳定数据面支持 HTTP/1.1、HTTP/2、SSE、WebSocket、gRPC、TCP、UDP 和 TLS。路由可匹配 host、path、method、header 与 SNI，并提供健康检查、负载均衡、限流、认证、重试、熔断、镜像和静态版本权重。

内置 Web Console 由 Management listener 提供，不依赖 Node.js 或外部静态资源：

```bash
a3s-gateway --config gateway.acl web
```

Console 读取真实的配置、拓扑、请求日志、性能和 Gateway 观察到的 trace。没有流量时保持空状态，不填充演示数据。

## Standalone 与 Cloud-managed

| 模式 | 期望状态归属 | Gateway 做什么 |
| --- | --- | --- |
| `standalone` | 本地 ACL | 校验并执行路由、协议、健康与中间件策略 |
| `cloud-managed` | A3S Cloud | 校验并应用完整、带版本和摘要的托管快照 |

托管快照绑定 Gateway ID、递增 revision、前一 revision、SHA-256、签发与过期时间。错误摘要、过期、冲突或陈旧的后继快照会被拒绝，当前快照继续生效。

## OpenAI 请求路径

Gateway 对 `/v1/models`、chat completions、legacy completions 和 embeddings 提供封闭的 OpenAI 请求 profile。它会校验 JSON、模型字段、授权和 grant，重写上游模型名，并且只在首个响应字节之前做 fallback。

这不是通用“兼容所有 OpenAI 扩展”的声明。未进入封闭 profile 的路由仍按普通代理路径处理。

## 哪些还不能宣传成已交付

| 能力 | 当前状态 |
| --- | --- |
| HTTP/SSE/WebSocket/gRPC/TCP/UDP/TLS | 已实现 |
| 原子 ACL reload 与托管快照 | 已实现 |
| 嵌入式运维 Console | `main` 已实现，列在 Unreleased |
| 本地 Coding Agent profile 与 Skill 启动 | `main` 已实现，列在 Unreleased |
| Standalone 自动扩缩容 | 实验性；真实 Box/Kubernetes 完整认证仍未完成 |
| 自动渐进发布与回滚 | 控制器类型存在，但没有运行循环；不可用 |
| 原生 MCP 或 Agent 协议数据面 | 计划中 |

旧文章曾把自动回滚和生产级扩缩容写成现成功能，这与当前 Roadmap 不符。

## 安装与最小验证

macOS 或 Linux：

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://a3s-lab.github.io/Gateway/install.sh | sh
```

Windows PowerShell：

```powershell
irm https://a3s-lab.github.io/Gateway/install.ps1 | iex
```

安装脚本校验发布包 SHA-256 和二进制版本。运行前先校验 ACL：

```bash
a3s-gateway validate --config gateway.acl
a3s-gateway config --config gateway.acl summary
a3s-gateway --config gateway.acl
```
