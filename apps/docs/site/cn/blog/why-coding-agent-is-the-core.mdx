A3S Code 的当前稳定版是 6.8.0。它不是一个只提供聊天循环的库，也不是把某个模型 CLI 包一层。它把 Coding Agent 的执行边界拆成可替换的契约：模型、工作区、工具、权限、事件和持久化。

## 最短使用路径

终端产品由 A3S CLI 提供：

```bash
brew install A3S-Lab/tap/a3s
cd /path/to/project
a3s code
```

已有应用可以直接嵌入 Rust Core，或使用 Node.js、Python 和 Go SDK。四个入口共享同一套 Session、事件和工具语义，不需要分别维护四个 Agent 实现。

## `Agent` 与 `AgentSession`

`Agent` 解析 ACL 配置并持有共享能力。`AgentSession` 把这些能力绑定到一个工作区和一段会话。

```rust
use a3s_code_core::{Agent, AgentEvent};

let agent = Agent::new("agent.acl").await?;
let session = agent.session_builder(".").build().await?;
let (mut events, lifecycle) = session.stream("Find the auth entry points.", None).await?;

while let Some(event) = events.recv().await {
    if let AgentEvent::TextDelta { text } = event {
        print!("{text}");
    }
}

let _ = lifecycle.await;
```

UI 不需要读取 Core 的内部状态。文本、工具调用、审批、计划、任务和终态都通过事件流交付。

## 工具不是一张无条件开放的表

Code 会根据工作区能力和策略注册工具。

- 本地工作区可以提供文件、Shell、Git、代码导航和下载。
- 只有对象存储能力的后端不会向模型暴露本地 `bash` 或 `git`。
- 每次调用仍要经过参数校验、权限、人工确认、预算、沙箱和取消链路。
- `batch` 只并行执行声明为安全只读的调用；写操作和未知工具串行执行。

6.8.0 把仓库发现统一到 `search`，支持正则内容搜索、路径 glob 和有界 BM25；把委派统一到 `task`，支持单任务或 1–32 项并发 fan-out。

## 恢复靠的是证据

`SessionSnapshotV1` 可以原子保存会话状态、运行、Artifact、Trace、验证报告和子任务记录。`EventEnvelopeV1` 是 SDK 与持久化运行共同使用的无损事件协议。

因此 `resume` 不是重新把聊天文本塞给模型。宿主可以读取已有运行、检查 checkpoint，并继续同一个权威 Session。

6.8.0 还加入了 `a3s.code.agent.v1` 头部协议，用于精确的 release、session、run 启动、取消、checkpoint 恢复和事件分页。它复用 Code 的运行存储，不再建立第二份 Harness 日志。

## 可编程能力

当前 Core 包含三类编排入口：

| 入口 | 适合的工作 |
| --- | --- |
| `task` | 模型驱动的单任务或并发委派 |
| `program` | 有界 QuickJS 脚本调用受允许工具 |
| `dynamic_workflow` | A3S Flow 支撑的可回放步骤、重试和恢复 |

`program` 不能递归调用自己或 `dynamic_workflow`。动态工作流也必须由宿主显式注册；“代码里有类型”不代表每个嵌入式应用都会自动启用。

## 6.8.0 与 main 的区别

稳定版 6.8.0 已包含统一 `task`、BM25 搜索、跨 SDK 的 detached run、头部 Agent 协议和 Go SDK。

当前 `main` 还增加了文件系统 Skill Catalog：按 repo/user scope 列出元数据，需要时再读取 `SKILL.md`，并支持路径级启用、禁用与变更通知。这部分仍在 `Unreleased`，使用稳定包时不要按 main 文档假设它已经发布。

## Code 在 A3S 里的位置

Code 负责 Agent 的执行语义。A3S Flow 负责持久工作流，A3S Box 负责本地隔离运行，A3S Gateway 负责流量，A3S Cloud 负责组织和期望状态。把这些职责塞回 Code 会让权限和恢复出现多份事实来源。
