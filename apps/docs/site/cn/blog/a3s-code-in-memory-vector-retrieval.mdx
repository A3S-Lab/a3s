The current A3S CLI `main` branch can add semantic retrieval to a Code session without introducing a vector database service. It builds a bounded index asynchronously, keeps vectors in session-owned memory, and releases them when the session closes. This capability is newer than the stable `a3s 0.11.1` release and should not be inferred from that binary.

## One governed search tool

The model does not receive a separate `vector_db` tool. A3S Code extends the existing `search` contract with five modes: `grep`, `glob`, `bm25`, `semantic`, and `hybrid`. Semantic mode uses exact cosine ranking over the admitted in-memory vectors. Hybrid mode combines lexical, path, and semantic channels with reciprocal-rank fusion and can add a deterministic MMR stage.

```json
{
  "mode": "hybrid",
  "query": "where is session cache invalidation handled",
  "include": "*.rs",
  "limit": 5
}
```

Every mode passes through workspace path checks, permission policy, timeouts, cancellation, result limits, and digest verification. While semantic indexing is building or degraded, exact and BM25 channels remain available and hybrid search can report a typed lexical fallback.

## Session-owned lifecycle

Session construction does not wait for embedding. Eligible text files are cataloged, chunked, batched, and embedded in the background. Non-text files are counted but never sent to the embedding route. The host bounds records, accounted bytes, provider requests, queue depth, shutdown time, and the optional readiness wait.

Building, partial, ready, degraded, and closed are explicit phases. Closing the session drains the worker and releases vector records and bytes. There is no durable vector cache or hidden vector database service.

## Local CPU enablement

The local route requires a CLI build with `local-cpu-embedding` and a trusted user ACL or deliberately selected `--config` file. Users do not need to prepare MiniLM or ONNX files:

```text
workspace_retrieval {
  enabled = true
  semantic_readiness_timeout_ms = 30000
  max_records = 100000
  max_bytes = 134217728
  shutdown_timeout_ms = 5000

  local_cpu {
    intra_threads = 2
  }
}
```

The empty managed form selects a revision-locked
`Xenova/all-MiniLM-L6-v2` bundle. A3S Power downloads the roughly 23 MiB ONNX
and tokenizer files over HTTPS on first use, applies byte limits and per-file
SHA-256 admission, serializes concurrent installers, and atomically stores the
verified bundle below the A3S data root. Later sessions re-admit and reuse it
offline. The provisioning library is linked into compatible CLI releases, so a
separate `a3s-power` daemon is not required. `--offline` and
`A3S_NO_AUTO_INSTALL=1` forbid a missing first-use installation without creating
a directory or receipt. Configuration validation does not download anything.

An explicit `artifact_manifest` remains available for self-managed or
enterprise-owned distribution. A remote OpenAI-compatible route is also
supported, but it requires an explicit trusted source-egress grant. Credentials,
download URLs, endpoints, headers, source text, and vectors are excluded from
diagnostics.

## DeepSeek and TUI diagnostics

The embedding route is independent from `default_model`. DeepSeek can own reasoning and tool calls while local CPU inference supplies vectors. Selecting DeepSeek never turns a chat endpoint into an embedding endpoint or sends source files there implicitly.

The footer shows retrieval readiness. `/status` reports coverage, files, chunks, queue and failures, vector records and bytes, revisions, embedding identity and dimension, batching efficiency, request amplification, first-ready latency, and non-text exclusions. Semantic and hybrid Explore cards show algorithms, channels, reranking, fallback, revisions, and digest verification. `Ctrl+T` expands the complete Retrieval evidence section without reflecting unknown metadata or secrets.

```bash
a3s --config .a3s/config.acl config validate
a3s --config .a3s/config.acl --output json config show
a3s --config .a3s/config.acl code
```

An automatically discovered workspace ACL is not trusted to enable embeddings or source egress.
